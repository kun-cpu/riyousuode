## 数据安全与兼容

倒计时为独立集合，不产生积分或奖惩。旧目标结算接口移除，兼容刷新入口为无操作；读取旧数据即迁移到 v3，任务刷新不会结算旧目标。

图片按内容 SHA-256 命名，存放应用私有目录，不依赖原相册 URI 的长期授权。保存记录前先验证并写入完整图片，再提交 Room 事务；删除和更换后清理未使用图片。恢复前快照内含图片，清理不影响快照恢复。

备份 v3 为 ZIP（data.json + images/），验证完整目录、路径、重复条目、数量、大小、JSON 结构、图片尺寸/格式及内容哈希。JSON 上限 10 MiB，ZIP 与解压总量各 64 MiB；倒计时最多 100 项，照片每张最多 512 KiB。校验或提交失败不覆盖数据库。

Android 8 图片方向回退解析只读取有边界检查的 JPEG orientation 字段；设备测试用带旋转标签的图片验证该解析结果，同时验证 API 30 的实际图片导入方向。
