# 0.3.2 每日任务跨日结算验证记录

日期：2026-10-16。应用标识 cn.riyousuode.app，versionCode 5，版本 0.3.2，沿用原签名。

## 行为

每日任务日期早于本地今天且状态仍待完成时，自动转为未完成，按该次任务的扣分及惩罚快照结算。今天的新任务独立生成。首页不再显示往日每日待确认项，补记入口为「我的 → 任务历史」。一次性任务仍保持原日期的待完成记录，继续在首页等待完成，不另建重复记录；每周任务保留原手动确认规则。

后台未打开应用的日期，在下次打开、系统提醒刷新或应用事务操作前补结算。前台跨日会触发刷新。自动结算与任务记录、积分、惩罚在同一 Room 事务中提交，重复刷新不重复扣分。已有待完成历史和恢复的备份同样使用新规则；已完成、豁免、已经确认的未完成不重复处理。

补记完成时按差额退回失败扣分并获得完成积分，未兑现惩罚撤回，已兑现凭证保留并标记更正。往日每日任务不能再恢复为待完成，避免重新堆积到首页。

每条打卡新增可选 kind 类型快照，旧版 v1/v2/v3 数据可读取。旧记录第一次刷新按当时任务类型补齐；之后修改任务类型不改变已有记录的跨日行为。备份仍为 v3 ZIP，新备份需要使用 0.3.2 或更高版本恢复。图片、记账及旧目标规则沿用。
